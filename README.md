## 📖 Introduction  
TourBuddy AI is an **AI-powered travel planner** designed as a one-stop solution for tourists exploring India.  
It combines **AI agents, multilingual support, React frontend, and voice assistance** to make trip planning interactive, personalized, and effortless.  

---

## 🎯 Objectives  
- 🗺️ Create a **comprehensive tourism portal** with all Indian states’ destinations.  
- 🏨 Provide accurate details (images, costs, accommodations, transport, culture).  
- 🤖 Integrate **AI-powered itinerary planner & voice assistant**.  
- 🎟️ Offer personalized recommendations based on **budget, time, and interests**.  
- 📈 Boost Indian tourism by promoting **hidden gems & local businesses**.  

---

## ✨ Key Features  
- 📌 **State-wise directory** of tourist attractions with images & highlights.  
- 💰 **Cost estimations** (entry fees, hotels, transport, food).  
- 🏨 **Nearby hotels & packages** with booking links.  
- 🚉 **Transport guidance** (bus, train, flight, cab).  
- 📅 **Best time to visit** (seasonal & festival details).  
- 🤖 **AI Agents**:  
  - 🧳 Travel Planner – personalized itineraries.  
  - 💸 Budget Optimizer – best options within budget.  
  - ❓ Q&A Guide – instant tourist query support.  
  - 🎙️ Voice Assistant – hands-free planning.  
  - 🌐 Multilingual Assistant – English, Hindi, regional languages.  
- 🧭 Smart recommendations (adventure, culture, history, nature).

## ▶️ Getting Started  

### 🔧 Installation  
```bash
# Clone the repo
git clone https://github.com/eswarreddy3/Tour-Buddy_AI.git
cd Tour-Buddy_AI

# Backend setup
cd backend
pip install -r requirements.txt
uvicorn main:app --reload

# Frontend setup
cd frontend
npm install
npm run dev
